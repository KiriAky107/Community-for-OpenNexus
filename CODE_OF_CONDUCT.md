# Code of Conduct

Community for OpenNexus requires respectful, constructive collaboration, accurate credit, license compliance, and protection of contributor and user privacy.

Harassment, discrimination, threats, spam, denial-of-service behavior, impersonation, plagiarism, fabricated attribution, malicious package submission, review manipulation, or publication of credentials, private keys, personal data, private reports, or user Vault content is prohibited.

This policy applies to Issues, Pull Requests, reviews, package-policy discussions, moderation, and other spaces representing the project. Maintainers may remove content, reject packages or contributions, lock discussions, revoke access, or restrict participation.

Use GitHub reporting controls for ordinary conduct concerns. Vulnerabilities and reports containing sensitive package evidence must follow [SECURITY.md](SECURITY.md) and remain private.
